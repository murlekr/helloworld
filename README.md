# helloworld

A minimal **Hello World** app that runs on:
- Web browsers (desktop)
- Mobile browsers (Android/iOS)

## Run locally

No package install is required.

```bash
python3 -m http.server 8080
```

Then open:
- `http://localhost:8080` on your computer
- `http://<your-machine-ip>:8080` on a phone in the same network

## Project files

- `index.html` – the app UI (responsive layout)
